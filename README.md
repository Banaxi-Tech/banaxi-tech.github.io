# banaxi-tech.github.io

Source of [banaxi-tech.github.io](https://banaxi-tech.github.io), built with
[Astro](https://astro.build) and [Starlight](https://starlight.astro.build).
Pushing to `main` deploys the site through GitHub Actions.

```sh
npm install
npm run dev      # local preview at http://localhost:4321
npm run build    # static site in dist/
```

Pages live in `src/content/docs/`; the sidebar is configured in `astro.config.mjs`.
