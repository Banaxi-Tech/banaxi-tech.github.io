## Windows

W32Eleven contains no Microsoft code.

:::danger[Don't redistribute patched Windows ISOs]
Windows is Microsoft's copyrighted software. Share the tool, and let everyone patch the ISO they downloaded from
Microsoft, as Rufus and Ventoy do. Windows still needs a valid license.
:::

## Embedded free software

The patched disc embeds third-party free software: GRUB (GPLv3), SeaBIOS and the VGA BIOS (LGPLv3). Distributing
these binaries requires including or offering their source code and license notices.
