## W32Eleven

An x86-64 PC emulator that runs directly on the hardware of 32-bit x86 machines. It boots from a patched Windows
DVD or USB stick and translates Windows' 64-bit code into 32-bit code with its own JIT. Windows isn't modified: it
sees an ordinary 64-bit PC.

<CardGrid>
  <Card title="No 64-bit CPU needed" icon="rocket">
    Runs on any i386-or-later CPU with an x87 FPU: no SSE and no 64-bit mode.
  </Card>
  <Card title="Bare metal" icon="seti:c">
    A small Multiboot kernel that GRUB loads directly, with no operating system underneath.
  </Card>
  <Card title="One patched ISO" icon="document">
    The patch tool turns Microsoft's Windows 11 ISO into a DVD or USB stick that boots the emulator first.
  </Card>
  <Card title="Hands-off install" icon="setting">
    An automatic install goes from the DVD to the desktop with no clicks, slimmed down for slow PCs.
  </Card>
</CardGrid>
